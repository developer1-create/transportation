# Transportation Project

## Project Overview
This repository holds the codebase for the transportation application, which includes a frontend built with Flutter, a backend developed in .NET 10 C#, and a database setup using SQL Server.

## Project Structure

```
transportation/
├── frontend/
│   ├── lib/
│   │   ├── main.dart  # Main entry point for the Flutter app
│   │   ├── screens/   # Contains all the screens of the app
│   │   └── widgets/   # Reusable widgets
│   ├── pubspec.yaml    # Flutter project configuration
│   └── README.md       # Frontend specific documentation
├── backend/
│   ├── Controllers/    # API Controllers
│   ├── Models/         # Data Models
│   ├── Services/       # Services to handle business logic
│   ├── transportation.sln # Solution file
│   └── README.md       # Backend specific documentation
└── database/
    ├── scripts/        # SQL scripts for database setup
    ├── migrations/      # Database migrations
    └── README.md       # Database specific documentation
```
